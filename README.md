# Золотая корочка

Учебный сайт-визитка вымышленной семейной пекарни. Проект выполнен для домашнего задания к уроку 9 курса «Основы нейросетей 2.0» с помощью ChatGPT и Visual Studio Code.

## Содержание сайта

Сайт состоит из четырёх экранов:

1. Главная страница с фотографией круассанов.
2. Ассортимент: круассан, хлеб на закваске и булочка с корицей.
3. О пекарне: история и фотография девушки-пекаря у печи.
4. Контакты: Новосибирск, пример адреса и часы работы.

Между экранами можно перемещаться кнопками «Назад» и «Далее», ссылками в верхнем меню или клавишами со стрелками влево и вправо. Оформление адаптируется к ширине и высоте окна браузера.

## Как открыть сайт

Скачайте проект целиком, сохранив папку `images` и файлы рядом с ней. Откройте `index.html` в браузере двойным щелчком. Установка программных пакетов и запуск сервера не требуются.

## Файлы проекта

- `index.html` — содержание и структура четырёх экранов.
- `styles.css` — цвета, шрифты, размеры и адаптивное оформление.
- `script.js` — переключение экранов, навигация и управление с клавиатуры.
- `images/` — четыре изображения для сайта.

## Использованные инструменты

HTML, CSS и JavaScript. Тексты и код подготовлены с помощью ChatGPT. Изображение круассанов создано в SeaArt с моделью FLUX в предыдущем учебном задании; остальные изображения созданы средствами генерации изображений ChatGPT.

## Учебные данные

Пекарня вымышленная. Адрес, часы работы и цены приведены для примера. Сайт не принимает заказы и платежи.
